How This Works (Core Concepts):

  • The Z-Axis: On a computer screen, the X-axis is horizontal and the Y-axis is vertical. The Z-axis represents depth (coming towards the user's eyes).
  • The z-index Property: Elements with higher numeric z-index values render on top of elements with lower values. Note: z-index only works on positioned elements (e.g. position: absolute or relative).
  • JavaScript Counter: We maintain a counter variable highestZIndex = 3. Whenever a box is clicked, JavaScript executes this.style.zIndex = ++highestZIndex;, guaranteeing the clicked box receives a higher depth value than all others.
