Academic Evaluation

Viva Voce Preparation — Key Concepts

Essential questions faculty examiners frequently ask during lab demonstrations:

Q1. Why use <iframe> instead of <frameset>?

The old HTML4 <frameset> and <frame> tags have been completely deprecated and removed in HTML5 because they broke browser bookmarking, history navigation, and mobile accessibility. HTML5 uses inline frames (<iframe>) which embed another HTML document seamlessly inside normal semantic page layouts.

Q2. How does hyperlink targeting work with iframes?

When an iframe is given an attribute such as name="content", any hyperlink with the attribute target="content" will open its destination inside that iframe rather than replacing the parent window or opening a new tab.

Q3. Why are semantic tags preferred over <div>?

Tags like <header>, <footer>, <article>, <section>, and <aside> convey meaning to web browsers, search engines, and screen-reading assistive technologies, improving accessibility and SEO without altering default visual behavior.

Q4. What is the difference between <section> and <article>?

An <article> represents a complete, self-contained composition that could theoretically be distributed or syndicated independently (like a blog post, news story, or model card). A <section> is a thematic grouping of content, typically with a heading.

Q5. How do you make a tabular form responsive?

Standard tables tend to overflow on mobile screens. In style.css, we apply a media query (@media (max-width: 768px)) that changes display: table-cell to display: block or flex. This gracefully stacks labels above inputs on narrow mobile devices.

Q6. What is the purpose of rel="noopener noreferrer"?

When opening external hyperlinks with target="_blank", malicious destination pages could access window.opener to hijack the referring page. Adding rel="noopener noreferrer" prevents this security vulnerability and prevents sending HTTP referer headers.

Q7. When should you use Flexbox vs. CSS Grid?

Flexbox is 1-dimensional (arranging items along either a row or a column), ideal for toolbars, navigation bars, and linear button groups. CSS Grid is 2-dimensional (controlling rows and columns simultaneously), ideal for overall dashboard layouts and card matrices.

Q8. How does client-side validation benefit forms?

HTML5 attributes like required, type="email", and JavaScript validation intercept invalid submissions before any network transfer occurs, providing immediate instant feedback to the user while preventing unnecessary server load.
