Viva Voce Questions & Answers

1. Why use an <iframe> instead of older <frameset>?

The HTML4 <frameset> element is obsolete and was removed in HTML5 because it broke URL bookmarking, search indexing, and mobile responsiveness. <iframe> is the modern standard for embedding external documents inside normal responsive layouts.

2. How does the target="content" attribute work?

When an iframe has name="content", any anchor tag with target="content" directs the browser to load that URL inside the iframe, preventing a full parent page refresh.

3. What is the benefit of semantic HTML?

Semantic tags like <header>, <main>, <section>, <article>, and <footer> convey structural meaning to assistive technologies (screen readers) and search engines, while improving code readability.

4. How is the tabular form made responsive?

While standard HTML tables use table-cell rendering on desktops, CSS media queries on small screens (e.g. @media (max-width: 768px)) switch table cells to block elements, allowing labels and inputs to stack naturally on mobile devices.

5. Why are CSS custom properties useful?

CSS variables (like --background and --border) define design tokens centrally. Updating a token in :root instantly updates colors and borders across the entire stylesheet.
