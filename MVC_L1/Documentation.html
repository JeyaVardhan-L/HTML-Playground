Lab Assignment 1: MVC Architecture Implementation

Objective: To build a basic web application from scratch using Node.js, Express, and EJS that successfully implements the Model-View-Controller (MVC) architectural pattern.

GitHub Repository Link:
https://github.com/JeyaVardhan-L/HTML-Playground/tree/main/MVC_L1

Tech Stack Used

  • Runtime: Node.js
  • Framework: Express.js
  • View Engine: EJS (Embedded JavaScript)

1. Project Setup

I initialized a new Node.js project using npm init -y and installed the required dependencies: npm install express ejs. I created three dedicated folders to enforce the MVC separation of concerns: models, views, and controllers.

2. The Model (Data & Logic)

File: models/messageModel.js
Role: Manages the application's data. I created a function getMessage() that returns the string "Hello from the Model!". This function is exported so the Controller can access it.

function getMessage() { return "Hello from the Model!"; } module.exports = { getMessage };

3. The View (UI Layer)

File: views/view.ejs
Role: Renders the user interface. I wrote standard HTML for the page structure. To display the dynamic data passed from the Controller, I used EJS syntax: <%= message %>.

<!DOCTYPE html> <html> <head> <title>MVC Lab</title> </head> <body style="font-family: Arial; text-align: center; margin-top: 50px;"> <h1>MVC Architecture Lab</h1> <!-- The <%= %> tags are EJS magic. They inject the variable --> <h2><%= message %></h2> </body> </html>

4. The Controller (Traffic Manager)

File: controllers/messageController.js
Role: Acts as the bridge between the Model and the View. It imports the getMessage function from the Model. I created a showMessage(req, res) function that calls the Model to get the data, and then uses res.render() to send that data to the View.

const { getMessage } = require('../models/messageModel'); function showMessage(req, res) { // Ask the Model for the data const data = getMessage(); // Pass that data to the View ('view.ejs') res.render('view', { message: data }); } module.exports = { showMessage };

5. The Server & Routing

File: app.js
Role: Sets up the server and defines the routes. I configured Express to use EJS as the view engine. I defined a single route: app.get('/', showMessage). This tells the server that when a user visits the home page, it should trigger the Controller's function.

const express = require('express'); const app = express(); // Tell Express to use EJS as our View Engine app.set('view engine', 'ejs'); // Import the Controller const { showMessage } = require('./controllers/messageController'); // When the user goes to the home page ('/'), run the showMessage function app.get('/', showMessage); // Start the server on port 3000 app.listen(3000, () => { console.log('Server is running on http://localhost:3000'); });

6. Execution & Output

To run the application, I executed the command node app.js in the terminal. Upon opening a web browser and navigating to http://localhost:3000, the application successfully executed the MVC flow and displayed:

Hello from the Model!
